The font metadata reports version 1.10; all four bundled styles contain 779 glyphs.

Regular is the default face for all controls and 3D labels. Existing large headings use Bold.
Rich text uses the matching Bold, Italic and Bold Italic faces; its code-text slot also
uses Regular to keep the requested family throughout the interface. The global theme also reaches unmodified XR Tools controls.

The font does not contain up/right arrow symbols used by the old UI. Map north uses vector
lines; skill connections use a caret; banking uses words. No unrelated font is required
for authored production labels. Dynamic player text can still use Godot system fallback
for languages outside this font's supported Latin/Cyrillic repertoire.
